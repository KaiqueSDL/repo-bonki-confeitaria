# Migração

Preservados 11 produtos, 13 imagens originais (bytes sem recompressão), 2 categorias, 3 slides, 4 acontecimentos e os contatos/avisos originais.

A primeira apresentação mantém as três imagens empilhadas. As demais imagens são referências de mídia independentes dos IDs dos produtos.

A história e a foto das fundadoras estavam com campos de preenchimento no original; os textos foram preservados, e a foto permanece sem cadastro. Nenhum dado real foi inventado.

O conteúdo é armazenado em data/content.json como seis coleções/documentos (products, categories, carousel, history, settings, media) para garantir alteração atômica entre referências.
